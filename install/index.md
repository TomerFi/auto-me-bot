Install **auto-me-bot** for GitHub [here](<https://github.com/apps/auto-me-bot>).

> [!NOTE]
>
> **Triggering events**
>
> - pull\_request
> - pull\_request\_review

> [!NOTE]
>
> **Required permissions**
>
> | scope | permission |
> | --- | --- |
> | .github/auto-me-bot.yml | read |
> | administration | read |
> | checks | write |
> | metadata | read |
> | pull\_requests | write |
>
> > metadata:read is mandatory.
